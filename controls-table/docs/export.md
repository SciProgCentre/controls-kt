Требования по запросам данных и их экспорту данных таблиц.

## Что экспортируем?

Таблицу из строк, где в каждой строке выдается время и набор значений, соответствующий в пределах "расстояния между строками" по времени.
Строки включают как информацию о значениях, так и служебную информацию. Например:
* Категории качества тэгов;
* Статус источников данных.

Строки могут содержать как сырые значения из TagTable, так и значения с внешних приборов (полученные через асинхронный интерфейс) и вычисленные значения.

## Когда экспортируем?

Экспорт синхронный и происходит по внешнему запросу. Экспорт не стоит использовать для построения графиков или мониторинга. Каждый запрос на экспорт содержит информацию о периоде, за который осуществляется экспорт, и о том, какие колонки должны в нем должны присутствовать. Не подразумевается возможность экспортировать "все данные".

## Сколько экспортируем?

В запросе на экспорт указывается период, за который делается экспорт, набор колонок, которые экспортируются, а также минимальный временной интервал между строками. Если строки идут более часто, то промежуточные значения игнорируются.

Для экспортируемых данных не используется дедупликация данных, то есть все значения в таблицах должны быть заполнены, даже если они повторяются.

## Параметры запроса на экспорт

* timeRange — диапазон времени, для которых делается запрос
* columns — набор описаний колонок. Каждая колонка может реализовать один из следующих типов:
    * tag — колонка таблицы тэгов.
    * property — свойство из прибора в DeviceManager

## Формат экспорта

### Текстовая таблица (Excel/CSV)

Таблица состоит из заголовка с машиночитаемыми именами и набора значений. В каждой строке обязательно наличие колонки `time`, содержащей время в ISO8601 формате. Значения в ячейках могут быть числами или строками. При невозможности преобразовать значение в число или строку, выдается ошибка. Все ячейки должны быть заполнены. Пустые ячейки не допускаются.

### Json

Json объект, содержащий два значения:
* header. Словарь объектов, где ключ — имя колонки, а значение описание колонки из запроса.
* rows. Список объектов, каждый из которых словарь, где ключ имя колонки, а значение — это значение для заданной колонки и строки. Значение может быть деревом.

## Kotlin API

`TableExporter` принимает индекс для каждой таблицы тэгов и хранилище сообщений устройств. В `export` нужно передать диапазон времени и явный список колонок; для тэгов также экспортируется колонка качества, если она есть в данных. Результат — `Table<Meta>` с колонкой `time` в формате ISO8601 и заполненными значениями колонок.
