# Module controls-exposed

An implementation of controls-storage on top of JetBrains Exposed JDBC.

## Usage

## Artifact:

The Maven coordinates of this project are `space.kscience:controls-exposed:0.4.0`.

**Gradle Kotlin DSL:**
```kotlin
repositories {
    maven("https://repo.kotlin.link")
    mavenCentral()
}

dependencies {
    implementation("space.kscience:controls-exposed:0.4.0")
}
```
