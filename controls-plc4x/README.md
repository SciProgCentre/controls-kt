# Module controls-plc4x

A plugin for Controls-kt device server on top of plc4x library

## Usage

## Artifact:

The Maven coordinates of this project are `space.kscience:controls-plc4x:0.4.0`.

**Gradle Kotlin DSL:**
```kotlin
repositories {
    maven("https://repo.kotlin.link")
    mavenCentral()
}

dependencies {
    implementation("space.kscience:controls-plc4x:0.4.0")
}
```
